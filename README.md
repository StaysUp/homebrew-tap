# Stays Up Homebrew tap

Homebrew formulas for [AgentBus](https://github.com/staysup/agentbus), a cross-vendor middleware
framework for coding agents.

```sh
brew install staysup/tap/agentbus
agentbus version
```

To upgrade: `brew upgrade agentbus`.

The formulas in `Formula/` are written by each AgentBus release. Please open issues in
[staysup/agentbus](https://github.com/staysup/agentbus/issues), not here.
